Задача: https://github.com/AgentSpore/freezewise/issues/9

## Решение

Данные ссылки разбираются при рендере без синхронного setState в effect.
Пустые, повреждённые и неверно структурированные данные не открывают диалог
и не вызывают поиск. Поля элемента проверяются, количество остаётся текстом,
место хранения ограничено существующими fridge/freezer/pantry.

Внутренний диалог получает key по параметру share. Удаление или смена query
обновляет его; закрытие убирает query, повторное открытие той же ссылки работает.
Существующие добавление продукта, подсчёт успешных импортов и частичные ошибки
сохранены. Завершение устаревшего запроса после закрытия или смены диалога
не меняет данные, не запускает следующий поиск, не показывает итоговый toast
и не выполняет навигацию. Lifecycle-защита учитывает setup/cleanup StrictMode.

## Проверки

Исходная lint-ошибка `react-hooks/set-state-in-effect` подтверждена до правки.
В промежуточной неопубликованной версии независимое ревью нашло гонку.
Browser RED воспроизвёл её после A→B и после закрытия: HTTP 200, ответ получен,
инвентарь ошибочно вырос с 0 до 1; при A→B исчез новый диалог. RED сохранён
отдельно и не перезаписывается. Исправление проверяет успешный и отклонённый
устаревший ответ до любых последующих действий.

Переносимый regression: `tests/e2e/test_import_share_browser.py`.
Нужны существующие Python Playwright/Chromium и Node с установленным lz-string;
новые зависимости приложения не добавляются. Запускайте тест против отдельного
loopback frontend с параметрами `--base`, `--output`, при необходимости `--node`.
Тест использует синтетические ответы поиска; внешний API и запись production
запрещены. Материалы проверки хранятся вне Git.

Проверки отдельной сборки и реального интерфейса должны подтвердить повреждённые,
пустые и валидные ссылки, смену query, закрытие и повторное открытие, успешный,
неуспешный и частичный импорт, задержанные success/rejection. Полный lint должен
иметь 0 ошибок; существующие 3 предупреждения учитываются отдельно. TypeScript
и build обязательны. При переносе точные source/test хеши сохраняются; прежний
результат комбинированной сборки не объявляется результатом отдельной сборки.

## Ограничения

Только компонент импорта, его regression и эта спецификация. Изменения backend,
manifest, lockfile, ESLint config, quantity editor и посторонних warnings исключены.
Независимое ревью и фактический browser GREEN нужны до публикации. Отдельное
наблюдение сетевых отмен на прошлой сборке не доказывает причину прежних 24
`net::ERR_ABORTED` и не подменяет приёмку этой версии.
