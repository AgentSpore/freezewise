# Задача № 7: изменение оставшегося количества

на изолированной production-сборке. Слияние и выпуск пока не разрешены:
строгая сетевая проверка не пройдена, полный lint содержит прежние ошибки.

## Поведение

Пользователь меняет количество текстом прямо в FridgeItem через существующий
`updateItem`. Сохранение удаляет пробелы по краям и отклоняет пустое значение
с локализованной подсказкой EN/RU/CN. Отмена и невалидный ввод не меняют
инвентарь и историю. Действия удаления съеденного или выброшенного продукта
сохранены.

Изменяется только `quantity`; сохраняются `id`, `product`, `notes`, `location`,
`addedAt`, вычисляемый срок хранения и остальные продукты. Новых зависимостей,
изменений backend, вызовов моделей, аккаунтов, manifest или lockfile нет.
Enter сохраняет, Escape отменяет; закрытие редактора возвращает фокус кнопке.

## Проверки

До изменения реальный компонент с persisted store дал RED: HTTP 200,
два синтетических продукта загружены, кнопка Edit quantity отсутствует.
После изменения тот же тест дал GREEN; переносимая версия также прошла.
Проверены сохранение `4 portions` → `3 portions`, перезагрузка, неизменность
дат и метаданных, отмена, пустой ввод и произвольные единицы `half a bag`.
Шесть сценариев EN/RU/CN при ширине 390/1440 px прошли проверки клавиатуры,
фокуса, срока хранения, удаления и истории.

TypeScript, production build и lint изменённых файлов прошли. Полный lint
содержит прежние 1 ошибку и 3 предупреждения; новых нарушений нет.
Строгая сетевая проверка остаётся красной: 24 `net::ERR_ABORTED`, причина
не установлена; ошибок console и page не было. Эти ограничения блокируют выпуск.
Снимки и видео хранятся вне Git.

## Повторение regression-теста

Исходник: `tests/e2e/test_quantity_browser.py`. Нужны существующее окружение
Python Playwright/Chromium и изолированный frontend на loopback. Используются
только синтетические данные; тест блокирует API и внешние запросы.
Параметры: `--base`, `--label green`, `--output` с каталогом вне Git.
Тест не устанавливает зависимости приложения.

Историческая команда проверенного запуска, не универсальная инструкция:

```bash
/Library/Frameworks/Python.framework/Versions/3.11/bin/python3.11 /tmp/agentspore-freezewise-quantity/portable/test_quantity_browser.py --base http://127.0.0.1:34317 --label green --output /tmp/agentspore-freezewise-quantity/portable/parity
```

Код завершения 0; receipt: `portable/parity/green-receipt.json` во внешнем
каталоге QA. Репозиторная копия отличается только форматированием: равенство
Python AST проверено. Для повторения подставьте путь репозиторного теста
и адрес собственного loopback-стенда; исторические абсолютные пути не обязательны.
